# Dapurnya. viaaa — Website Resmi

Website resmi untuk usaha kuliner **Dapurnya. viaaa** yang berlokasi di Jl. Raya Gading Tutuka, Cingcin, Kec. Soreang (Depan Taman Kota Soreang), Bandung, Jawa Barat.

---

## 🌟 Spesialisasi Menu Best Seller
1. **Udang Keju Crispy (Ala Gacoan)**: Olahan udang cincang gurih berbalut tepung roti emas renyah dengan keju mozarella lumer di bagian tengahnya.
2. **Dimsum Keju Lumer Goreng**: Dimsum goreng bertekstur krispi di luar dengan isian ayam-udang dan keju leleh di dalam.
3. **Basreng Bumbu Chili Oil Daun Jeruk**: Bakso goreng stik renyah dibaluri racikan minyak cabai aromatik dan wangi daun jeruk segar.
4. **Cireng Isi Spesial**: Cireng renyah kenyal dengan varian isian ayam suwir pedas gurih serta keju lumer.
5. **Minuman Segar Dingin**: Es Teh Manis Melati, Es Jeruk Peras Alami, Es Cincau Susu Gula Aren.

---

## 🚀 Fitur Utama
- **Hero Section**: Rekonstruksi visual booth gerobak Dapurnya. viaaa, ornamen rempah kuliner, fitur *Pesan Cepat* dan *Menu Spesial*, serta tombol pemesanan langsung.
- **Katalog Menu Interaktif**: Filter kategori menggunakan navigasi bergaris bawah minimalis tanpa *pill badge*.
- **Keranjang Belanja & WhatsApp Direct**: Pemilihan porsi, tingkat kepedasan, metode pemesanan (*Takeaway*, *Delivery*, *Dine-in*), serta generator pesan WhatsApp otomatis yang rapi dan terstruktur.
- **Integrasi Google Reviews**: Menampilkan rating resmi 4.9 dari ulasan nyata Google Maps di Soreang dengan tautan langsung menuju formulir ulasan Google Maps.
- **Peta Lokasi & Jadwal Operasional**: Embed Google Maps resmi Soreang dengan penegasan jadwal operasional (Selasa Libur).

---

## 🛠️ Stack Teknologi
- **Framework**: React 18 + TypeScript + Vite
- **Styling**: Tailwind CSS v3
- **Icons**: Lucide React
- **Typography**: Google Fonts (*Plus Jakarta Sans* & *Outfit*)

---

## 💻 Panduan Menjalankan Secara Lokal

```bash
# 1. Pastikan dependensi telah terpasang
npm install

# 2. Jalankan server pengembangan lokal
npm run dev

# 3. Bangun bundel produksi
npm run build
```
